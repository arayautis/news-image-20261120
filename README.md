## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

`main.py` (Python 3.13, standard library only) copies the `entry.png`
this repository holds to `/output/entry.png`. `compose.py` is the
generator that drew it (needs Pillow, only used at build time, never
by the entry program).
